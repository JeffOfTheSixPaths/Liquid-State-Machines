# Introduction

A Liquid State Machine (LSM) is a type of reservoir computing (RC) layer that's made up of a layer of neurons that are connected recurrently within that layer.
An LSM uses leaky-integrate-and-fire neurons (LIF neurons) that are commonly used in Spiking Neural Networks (SNNs)

# What this repo is
